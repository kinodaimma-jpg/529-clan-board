# 5-29 클랜 익명 게시판 업데이트

기존 5-29 게시판을 유지하면서 화면과 기능만 업데이트하는 패키지입니다.

## 이번 업데이트
- 게시판 목록과 글쓰기 화면 분리 (`글쓰기` 버튼으로 이동)
- 왼쪽 카테고리 메뉴: 전체 / 자유 / 건의사항 / 비매너 / 공지사항
- 게시글별 카테고리 저장 및 필터링
- 관리자 로그인 후 카테고리 이름 변경 (모든 클랜원에게 공통 적용)
- 사용자별 1분 게시글 작성 제한 (화면과 서버 양쪽에서 검사)
- 기존 배너 편집, 관리자 게시글/댓글 관리 기능 유지

## 적용 순서

### 1. Supabase SQL 업데이트 (한 번만)
1. Supabase 프로젝트의 SQL Editor를 엽니다.
2. 이 폴더의 `supabase/upgrade_categories_cooldown.sql` 파일을 엽니다.
3. 파일의 SQL 전체를 SQL Editor에 붙여넣고 Run을 누릅니다.
4. 성공 메시지가 나오면 다음 단계로 갑니다.

이 SQL은 기존 테이블과 데이터를 삭제하지 않습니다. 기존 게시글은 `자유` 카테고리로 분류됩니다.

### 2. Netlify에 업데이트 배포
1. `529-clan-board` 폴더 안의 `index.html`, `netlify` 폴더, `netlify.toml`, `supabase` 폴더가 함께 있는지 확인합니다.
2. Netlify의 기존 사이트 `529-ing` → Deploys로 이동합니다.
3. 배포 화면의 드롭 영역에 이 `529-clan-board` 폴더 전체를 끌어다 놓습니다.
4. 새 배포가 Published가 될 때까지 기다립니다.

기존 Netlify 사이트에 덮어쓰는 배포입니다. 새 사이트를 만들 필요가 없습니다.

## 환경변수
기존 Netlify 환경변수는 그대로 사용합니다: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `CLAN_PASSWORD`, `SESSION_SECRET`, `ADMIN_PASSWORD`.
값을 새로 만들거나 변경할 필요는 없습니다.

## 데이터 보존
게시글, 댓글, 추천, 배너 및 카테고리 설정은 Supabase에 저장됩니다. 이 패키지는 기존 데이터를 삭제하거나 초기화하지 않습니다.
